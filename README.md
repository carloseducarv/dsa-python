# Fundamentos de Linguagem Python - Do Básico a Aplicações de IA

Repositório criado para armazenar os exercícios, exemplos, anotações e projetos desenvolvidos durante o curso **Fundamentos de Linguagem Python - Do Básico a Aplicações de IA**, da Data Science Academy (DSA).

## 📚 Sobre o Curso

O curso aborda os principais fundamentos da linguagem Python, desde os conceitos básicos de programação até aplicações voltadas para Inteligência Artificial, Ciência de Dados e automação.

## 🎯 Objetivo do Repositório

* Registrar minha evolução ao longo do curso;
* Organizar exercícios e exemplos práticos;
* Consolidar conhecimentos em Python;
* Servir como material de consulta para estudos futuros.
